CTF 档案用于沉淀安全题目的分析路径，而不是只保存最终 payload。先记录环境和异常，再定位输入边界，最后整理利用链、证据与修复方式。

## 分类方法

| 方向 | 观测入口 | 复盘重点 |
| --- | --- | --- |
| Web | 参数、Cookie、上传、模板 | 输入如何进入危险函数 |
| Crypto | 参数、明文结构、随机数 | 哪个数学前提被破坏 |
| Reverse | 字符串、控制流、加密函数 | 输入如何被变换与比较 |
| Pwn | 保护机制、栈/堆布局、libc | 漏洞原语与利用链稳定性 |
| Misc | 文件格式、流量、隐写、取证 | 证据链与工具验证 |

## 复盘格式

- 环境：题目文件、运行方式、依赖版本。
- 现象：异常回显、崩溃点、响应差异。
- 分析：漏洞成因、关键代码、验证证据。
- 利用：payload、脚本、边界条件。
- 修复：参数化、权限控制、输入校验或安全配置。
